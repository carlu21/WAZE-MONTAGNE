# Revue du MVP — constats et suivi

Revue multi-angles (conformité au cahier des charges, correction web et API, sécurité et vie privée, hors connexion, ergonomie extérieure) réalisée sur la branche du MVP : 110 constats bruts. Les constats critiques et importants ont tous été traités ; les constats moyens et mineurs restants sont listés ci-dessous pour les prochaines itérations.

## Critique — 4 constats (4 traités, 0 ouverts)

- ✅ traité — **Le cache TanStack n'est pas vidé à la déconnexion : le compte suivant voit le profil, l'e-mail et les notifications de l'utilisateur précédent** (`apps/web/src/store/session.ts`, section 15, 23, 28)
- ✅ traité — **Secret JWT par défaut « dev-secret-change-me » sans garde-fou en production : jetons admin forgeables** (`apps/api/src/config.ts`, section 28)
- ✅ traité — **Tuiles hors connexion mises en cache sous le mauvais sous-domaine : la carte reste vide sans réseau** (`apps/web/src/features/offline/tiles.ts`, section 9)
- ✅ traité — **Le cache SW « api » sert les données personnelles d'un autre compte (/auth/me, /notifications) quand le serveur est injoignable** (`apps/web/vite.config.ts`, section 28)

## Hors périmètre de cette revue

- Les erreurs de chargement des tuiles cartographiques observées dans l'environnement de test proviennent du proxy du bac à sable (réseau externe bloqué) et ne concernent pas l'application.
- Les itinéraires (section 13) et les notifications push restent des évolutions planifiées (voir ROADMAP.md).
